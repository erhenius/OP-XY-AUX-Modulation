# Integrated AUX modulation runtime test

Run from this folder with `python3 run.py --sdk /path/to/prepared-sdk`. Use the Open-XY 0.0.7 checkout after applying the standalone AUX modulation extension's support patch. A C++11 host compiler with undefined-behavior sanitizer support is required. The test builds and runs in a temporary directory.

The test compiles the actual SDK GUI dispatcher and hidden-page service. It runs once with zero control machines to check both FX sends and again with a Morph identity and instrument callback fixture to cover the occupied CV track. In both configurations it drives the GUI AUX service through Shift+M4, encoder turns and clicks, accepts selections through the stock-browser callback, and publishes the real service's marker to a separate simulated audio-role bank. It calls the real audio evaluator, microphone callbacks, project companion section writer and reader, and new-project clear handler. Stock OS calls are doubles, with the Duck kernel returning a known envelope. Native Value table reads are redirected to a host sine table. The source-module test separately compares that waveform with every entry of the authenticated stock table.

Verified behaviors include ownership of the Morph track, both sends running concurrently, quiet CV output while Morph holds the track, preserved stock input forwarding, gyro polarity, live mic versus external or stale input, separate Random timing, all four Value shapes, positive Duck attenuation and zero amount, and the note/audio Duck selector. The project test writes current and inactive patterns, clears the project, restores it from a valid companion and rejects a same-length project with an incorrect checksum. It also exercises stale picker confirmation, unsupported source tags, a disabled LFO and returning from a different pattern.

This host test starts at the C++ side of the audio assembly hook. The precise Blackfin stack layout, stock native UI rendering, transport latency, hardware interrupt timing and actual Duck kernel execution require native or hardware tests.
