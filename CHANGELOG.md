# Changelog

## 1.0.0

First public release. Promotes the hardware-tested 0.3.0-a3 implementation. The extension ID, native source, SDK patches and saved mode numbers match A3.

- Independent Duck, Element, Random and Value on FX I and FX II, with optional Morph movement on the CV track.
- Shift+M4 family selection and original stock screens.
- Standalone TE Builder repository and ZIP import.
